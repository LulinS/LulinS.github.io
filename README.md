# lulins.github.io

Personal academic site for Lulin Song, built with Jekyll and hosted on GitHub Pages.

- `index.md`, `research.md`, `cv.md`, `personal.md` — page content
- `_config.yml` — name, email, links, and navigation
- `_layouts/default.html`, `_includes/sidebar.html`, `assets/css/site.css` — layout and style
- `files/LulinSong_CV.pdf` — the CV linked from the sidebar and CV page

Run locally: `bundle install && bundle exec jekyll serve`.
